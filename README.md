##  Purpose & Overview

**EduVibe** is a modern, responsive **Online Learning Platform** designed to make course discovery and digital education seamless for students and instructors.

It provides an intuitive user interface to help learners search, explore, and enroll in courses without any hassle.

##  Key Features

Real-Time Search & Filtering:** Filter courses instantly by title, instructor name, or specific subject category.
 Secure Authentication:** Easy user login and sign-up with Email/Password and Google OAuth.
Interactive Course Gallery:** Beautifully designed course cards, detailed syllabus view pages, and pricing details.
 Fully Responsive Design:** Optimized for mobile phones, tablets, and desktop displays.
 Modern UI & Fast Performance:** Clean styling, fast load times, and smooth user interaction.
